## Config

`/statusline Git branch. Model. Context.`

Use hook to automatically trigger some command (test, lint) when certain tasks are done.


## Usage

`AskUserQuestionTool` to force Claude ask you question

`/rewing` to go back if we made a wrong decision. Better than say "ok, undo this" because it removes wrong direction from context window.

`ctrl S` to stash / unstash your current prompt.

`/focus` to hide details, just prompt and result.

`/goal` give an expected result and a way to verify it. Claude does the rest.

`claude agents` to see current agents running
